# Трекер трат 📊

Личный трекер расходов для айфона (PWA — работает как обычное приложение, без App Store).

## Что умеет

- **Расходы, переводы и доходы** — раздельный учёт: траты идут в статистику по категориям, переводы (маме на карту, себе между счетами, снятие наличных) и доходы считаются отдельно.
- **Категории и описания** — у каждой траты своя категория (редактируются, можно добавлять свои) и описание.
- **Подписки** — название, сумма, валюта, дата следующего списания, ежемесячно/ежегодно. Видно, сколько выходит в месяц и что скоро спишется. Кнопка «✓» записывает оплату в расходы и сдвигает дату.
- **Долги** — «мне должны» и «я должен»: кто, сколько и за что. Долг — это набор записей: при добавлении долга тому же человеку приложение предлагает объединить записи (все описания сохраняются), при встречном долге — взаимозачёт. Частичные погашения с историей, полное закрытие в один тап.
- **Две валюты** — суммы в ₴ или $, конвертация по актуальному курсу (Monobank, запасной — НБУ). Курс можно задать вручную.
- **Импорт из Monobank** — подключите карту по токену персонального API и импортируйте выписку: категории проставятся автоматически по MCC-коду, переводы отделятся от расходов, дубли не создаются.
- **Всё редактируется** — любая операция, подписка, долг и категория открывается по тапу.
- **Приватность** — все данные хранятся только на вашем устройстве (localStorage). В настройках есть резервная копия (скачать/восстановить JSON).
- **Офлайн** — после первого открытия работает без интернета (кроме курса и импорта).

## Как установить на айфон

1. Опубликуйте сайт (проще всего — GitHub Pages):
   - в репозитории: **Settings → Pages → Source: Deploy from a branch**, выберите ветку и папку `/ (root)`;
   - через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/tracker/`.
2. Откройте этот адрес в **Safari** на айфоне.
3. Нажмите **Поделиться → На экран «Домой»**.
4. Готово: на рабочем столе появится иконка, приложение открывается на весь экран.

> Данные привязаны к устройству и браузеру. Иногда скачивайте резервную копию («Ещё → Данные»), особенно перед сменой телефона.

## Как подключить Monobank

1. Зайдите с телефона на [api.monobank.ua](https://api.monobank.ua) и подтвердите вход в приложении mono — получите токен.
2. В трекере: **Ещё → Monobank** → вставьте токен → «Подключить».
3. Выберите карту и период → «Импортировать операции».

Токен хранится только на вашем устройстве и используется исключительно для запросов к API Монобанка напрямую. Monobank ограничивает частоту запросов (1 запрос выписки в минуту) — если увидите такое сообщение, просто подождите минуту.

## Локальный запуск

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

Без сборки и зависимостей: чистый HTML/CSS/JS.

## Структура

```
index.html            — каркас приложения
css/style.css         — стили (тёмная тема, мобильная вёрстка)
js/store.js           — данные: localStorage, валюты, даты
js/api.js             — курс валют (Monobank/НБУ) и Monobank personal API
js/app.js             — экраны, формы, обработка действий
sw.js                 — офлайн-кэш
manifest.webmanifest  — метаданные PWA
icons/                — иконки приложения
```
