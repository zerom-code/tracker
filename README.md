# Трекер трат

Личный трекер расходов для iPhone. Устанавливается на экран «Домой» и работает как обычное
приложение — без App Store и без установки чего-либо на компьютер. Данные хранятся только
на устройстве.

Чистый HTML, CSS и JavaScript: ни сборки, ни фреймворков, ни зависимостей.

## Возможности

**Учёт операций**

- Три типа операций: расходы, переводы и доходы. Переводы (между своими счетами, людям,
  снятие наличных) входят в общую сумму расходов и одновременно показаны отдельной строкой
  «из них переводы» — видно и общую картину, и долю переводов. Доходы считаются отдельно.
- У каждой операции своя категория и описание. Категории редактируются, можно добавлять свои.
- Помесячная статистика: расходы, доходы, переводы и разбивка по категориям с долями.

**Регулярные платежи**

- Подписки: название, сумма, валюта, дата следующего списания, ежемесячно или ежегодно.
  Видно, сколько уходит в месяц и что спишется в ближайшие дни. Одно нажатие записывает
  оплату в расходы и сдвигает дату на следующий период.
- Кредиты и рассрочки: то же самое плюс план платежей — кому платим, сколько платежей всего
  и сколько уже внесено. В списке видно «платёж 4 из 12», прогресс и остаток к выплате;
  после последнего платежа рассрочка закрывается сама.

**Долги**

- Два направления: «мне должны» и «я должен» — кто, сколько и за что.
- Долг хранит список записей: если добавить новый долг тому же человеку, приложение
  предложит объединить их, сохранив все описания по отдельности.
- Встречный долг предлагается зачесть: запись о нём сохраняется и сразу помечается погашенной
  на зачтённую сумму.
- Частичные погашения с историей, полное закрытие в одно нажатие.

**Валюты**

- Гривна и доллар в любой комбинации. Итоги считаются в выбранной валюте учёта,
  суммы в другой валюте пересчитываются по курсу.
- Курс подтягивается автоматически (Monobank, запасной источник — НБУ) и может быть задан вручную.

**Импорт из Monobank**

- Подключение по токену персонального API. Выписка импортируется за сегодня, неделю, месяц
  или произвольный период.
- Категории проставляются автоматически по MCC-коду продавца, переводы и снятие наличных
  отделяются от трат, поступления попадают в доходы.
- Повторный импорт того же периода не создаёт дубликатов, а вручную удалённые операции
  не возвращаются.

**Автосинхронизация и уведомления** — необязательно, требуется свой сервер

- Monobank отправляет операцию на ваш сервер в момент оплаты, приложение забирает её
  при открытии — без лимитов на запросы и без выбора периодов вручную.
- Push-уведомления на iPhone: новые траты, поступления, переводы, напоминания о подписках
  и рассрочках. Каждый вид отключается отдельно, есть порог суммы и настройка,
  за сколько дней и в котором часу напоминать.
- Развёртывание описано в [`server/README.md`](server/README.md).

**Приватность и офлайн**

- Все данные — операции, подписки, долги, категории, токен Monobank — хранятся
  в браузере на устройстве и никуда не отправляются.
- Резервная копия в JSON: скачать и восстановить в разделе «Ещё».
- После первого открытия приложение работает без интернета; сеть нужна только
  для курса валют, импорта и синхронизации.

## Установка на iPhone

1. Опубликуйте сайт. Проще всего через GitHub Pages: **Settings → Pages → Source:
   Deploy from a branch**, ветка с кодом и папка `/ (root)`. Через минуту сайт будет
   доступен по адресу вида `https://<логин>.github.io/<репозиторий>/`.
2. Откройте этот адрес в **Safari** на iPhone.
3. **Поделиться → На экран «Домой»**.

Приложение появится на рабочем столе и будет открываться на весь экран.

> Данные привязаны к устройству и браузеру. Перед сменой телефона или очисткой Safari
> скачайте резервную копию в разделе «Ещё → Данные».

## Подключение Monobank

1. Откройте [api.monobank.ua](https://api.monobank.ua) с телефона и подтвердите вход
   в приложении банка — там выдаётся токен персонального API.
2. В трекере: **Ещё → Monobank**, вставьте токен, нажмите «Подключить».
3. Выберите карту и период, нажмите «Импортировать операции».

Токен хранится только на устройстве и используется для прямых запросов к API банка.
Monobank ограничивает выписку одним запросом в минуту.

## Локальный запуск

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Структура проекта

```
index.html            каркас приложения
css/style.css         стили: тёмная тема, мобильная вёрстка
js/store.js           данные, валюты, даты
js/api.js             курс валют и Monobank personal API
js/sync.js            синхронизация со своим сервером и push-уведомления
js/app.js             экраны, формы, обработка действий
sw.js                 офлайн-кэш и приём push
manifest.webmanifest  метаданные PWA
icons/                иконки приложения
server/               необязательный сервис уведомлений для VPS
```

## Требования

Современный браузер с поддержкой Service Worker. Push-уведомления работают
на iOS 16.4 и новее и только в приложении, добавленном на экран «Домой».
